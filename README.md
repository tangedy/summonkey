# Summonkey

A puzzle platformer about a wizard monkey and the box-lifting golem he summons.
Ported to Godot 4.7 from our Waterloo Game Jam (Fall '24) pygame entry.

## Controls

| Key | Action |
| --- | --- |
| A / D (or arrows) | Move |
| W / Up / Z | Jump (monkey only, about one tile) |
| K / X | Summon the golem in front of you; then swap control monkey <-> golem |
| Space / J | Golem: lift the stack in front (max 3) / put it down |
| L | Dismiss the golem (anything it carries drops) |
| R | Restart |
| Esc | Back to the title screen |

The golem lasts 30 seconds, can't jump, and can carry the monkey: stand on a
stack before the golem lifts it and you ride up two tiles (the "elevator").

A faint golem silhouette shows where K will summon. The level is proven
beatable by `tools/solve_level_01.gd` (about 37 s, 4 summons).

## Layout

- `scenes/`: `title.tscn` (main), `game.tscn`, `monkey`, `golem`, `box`, `banana`,
  `level_01_lighting.tscn` (ambient tint, lights on the painted lamps/windows, dust),
  `post_fx.tscn` (vignette + colour grade shader in `shaders/`)
- `scripts/music.gd`: autoload `Music`; crossfades `menu` (title + gameplay) and `win`
- `scripts/`: one script per scene; `level.gd` builds a level from an ASCII map
- `levels/level_01.txt`: the map (`#` wall, `.` air, `M` start, `B` box, `N` banana).
  Walls are invisible collision; the look comes from the painted background in
  `assets/backgrounds/`. The grid is 45 px per tile, matching the art.
- `resources/*_frames.tres`: generated by `tools/gen_spriteframes.py` from the
  frame folders in `assets/sprites/`. Re-run it after adding frames.
- `tools/playtest.gd`: scripted smoke test of every mechanic;
  `tools/solve_level_01.gd`: plays the whole level with inputs only. Both save screenshots:
  `godot --path . -s tools/solve_level_01.gd -- /some/dir/for/screenshots`
- `tools/make_carry_pose.py`: the golem's carry pose (final lift frame, box removed)

Lighting note: the background is painted with its own lighting, so it sits on
light layer 2 and the level's lights (layer 1) only light characters and boxes.
The staff, golem and banana lights hit both. HDR 2D stays off: in 4.7 with
viewport stretch it renders far too dark.

When exporting, add `*.txt` to the export preset's non-resource include filter
so the level maps ship with the build.
